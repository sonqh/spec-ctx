## Interpretation

- The detection of the OpenSpec version runs only when `init` writes `spec-ctx.toml`. `init` never edits an existing file, so a project that has the file keeps its `[gate] openspec` value or its default. The brief said "only when `[gate] openspec` is absent from an existing spec-ctx.toml". Adding a key to a file the user owns would break SCN-DIST-002-4, so the existing file stays as it is.
