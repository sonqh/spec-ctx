## Tests that failed on this machine before the change

- The full `bun test` failed 21 tests on this machine before any edit of this change, also on the base branch. The machine runs macOS 27 with bash 3.2. CI runs on Linux, so it did not see them. Each fix is in the tests or in a script. No engine code changed for them.
  - macOS 27 has no `/bin/true`. 16 tests set `SPECCTX_OPENSPEC` to `/bin/true`. They now use the shell builtin `true`, which runs also with an empty `PATH`.
  - `tests/verify/run.test.ts` compared a temp path with `pwd`. macOS links `/var` to `/private/var`. The test now compares real paths.
  - SCN-IDX-014-3 in `tests/index/same-tick.test.ts` needs a file that is newer than the file it rewrites. APFS keeps fine mtimes, so the rewritten file was the newest one. The test now writes one more file before `build`.
  - `scripts/replay-rerun.sh` passed an empty array under `set -u`. Bash 3.2 calls that unbound. The script now uses `${files[@]+"${files[@]}"}`.
  - `scripts/ci-local.sh` read `SPECCTX_CI_STEPS_FILE` with `mapfile`. Bash 3.2 has no `mapfile`. The script now uses a read loop. Its step loop uses the same empty array form as `replay-rerun.sh`.
- The shell steps of `bun run ci:local` failed in four more places on this machine. Each fix also runs on Linux.
  - `tests/action/rerun.sh` compared the output of `wc -l` with `1`. BSD `wc` puts spaces before the number. The test now strips them.
  - `tests/paths/fresh.sh` and `tests/paths/fresh-brackets.sh` used `sed -e '${/^$/d}'`. BSD `sed` needs a `;` before the brace.
  - `tests/gov/version-guard.sh` used the GNU form `sed -i`. It now uses `perl -pi -e`.
  - `tests/release/published.sh` ran the linux x64 release binary. It now checks the binary only on linux x64, and says so when it skips.
- After these fixes, `bun run ci:local` prints `ci-local: ok, 14 steps`.
