## The templates path

- `openspec/templates/spec-driven-ids/`. Upstream 1.15.0 reads a template only from `<schema dir>/templates/` of the resolved schema, in `dist/core/artifact-graph/instruction-loader.js`, function `loadTemplate`. `openspec templates --json` reports `source: package` for the stock schema whatever the project holds under `openspec/templates/`. A project override of the stock templates needs a full `schema.yaml` copy. That copy is what this change removes. So the templates are a reference. One rule in `openspec/config.yaml` names the path, and the `templates:` line of `init` names it too.
