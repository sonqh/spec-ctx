- The fixture `spec-ctx.toml` scans `tests/**`. The fixture keeps its tests in `test/`. So the tests glob matches no file there. The fixture has 0 test labels. This goes to change E.
- Only 1 of the 20 fixture tasks has a file label (`src/core/config.ts`, task `add-tool-command-surface-capabilities/1.1`). An open task has no closing commit, and its text rarely names a file. The code recall of the fixture rests on one label and says nothing.
- The structural edges of change 046 give high requirement recall only for small changes. The 5 tasks of `unify-template-generation-pipeline` match 5 of 5 each, at about 5,100 chars. The tasks of `add-global-install-scope` match 2 of 14. Their delta requirements do not fit in 8,000 chars. Each bundle shows 8,100 to 8,200 chars. Overall fixture requirement recall is 0.34. It is not high on open tasks.
- On this repo the requirement recall is 0.91. Code recall is 0.57 and test recall is 0.47. Most misses are files that the task text names, such as `src/cli/commands.ts`. Task 048/3.1 matches 3 of 14, and 046/2.1 matches 6 of 13. Both fill the budget with 8,444 and 8,469 chars.
- The median bundle is 7915 chars on this repo. It sits at the budget, so extra entries displace others.
- This repo does not scan `scripts/`. So `context 053/1.1` does not show `scripts/try.sh`. A one line `spec-ctx.toml` change fixes it, after the baseline.
