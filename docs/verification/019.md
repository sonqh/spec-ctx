# Verification of change 019-task-done-contract

## Tasks

- 019/1.1 The `--manual` branch of `task done` in `src/cli/workflow.ts` exits 2 with `task <t> has a Verify command. Run it with specctx task done <t>.` when the task line has a Verify code span. `tests/tasks/done.test.ts` covers SCN-TASK-003-5 on an open task, on a hand ticked task, and with the allowed case of a prose Verify. The test failed before the fix. `tests/check/evidence.test.ts` gave its manual task a prose Verify, because the old test called `--manual` on a task with a code span.
- 019/1.2 The repair path. `task done` on a `[x]` task exits 2 only when the evidence file exists. Without it the Verify command runs through the same code as an open task. Exit 0 writes the evidence and keeps the box. A failure prints the same text as on an open task and touches nothing. `tests/tasks/done.test.ts` covers SCN-TASK-003-6 and checks that `check --strict` keeps `done-without-evidence` after the failure and drops it after the pass.
- 019/1.3 `task start` writes `verify` into `.ctx/current.json`. `task done` reads the file before the run and exits 2 with `task <t>: the Verify command changed since task start. Run specctx task start <t> again.` when the file names this task and the command differs. `tests/tasks/start.test.ts` covers SCN-TASK-002-5 and the exact file text of SCN-TASK-002-1 now holds the `verify` key. `tests/tasks/done.test.ts` covers SCN-TASK-003-7, with the case of a `current.json` that names another task.
- 019/2.1 `task backfill` left `workflow.ts`, `args.ts`, and `help.ts`. The hint of `done-without-evidence` names `specctx task done` alone. `tests/tasks/backfill.test.ts` is gone. The baseline tests drop the backfill call and assert `done-without-evidence add-mfa/1.1` and `add-mfa/1.2` instead of `manual-evidence add-mfa/1.1`. The help test asserts that no line names `task backfill`. The freeze of 1.3 caught its first real case here. The Verify grep of 2.1 matched the help test, so I narrowed the grep to `src/` on the task line. `task done` refused with the new message, and `task start 019/2.1` again unfroze it.
- 019/3.1 `tests/paths/existing.sh` and the README existing path drop the `task backfill` line. The script asserts `done-without-evidence add-mfa/1.1` in the baseline. `CHANGELOG.md` gets the three contract items under Changed and the removal under Removed. `bun run ci:local` passed.
