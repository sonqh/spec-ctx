# Verification of change 027-bracketed-ids

## Tasks

- 027/1.1 `REQ_HDR` and `SCN_HDR` in `src/index/scan.ts` have a bare group and a bracketed group. The bracketed group needs whitespace or the end of the line after the closing bracket, as the upstream pattern does. `tests/index/scan.test.ts` covers SCN-IDX-006-1 to SCN-IDX-006-4. Three of the four tests failed before the change. SCN-IDX-006-4 passed before and after, because a bracket without a spec-ctx ID was never an ID. The first run of that test was flaky: the four writes had the same mtime, so the index did not rebuild. Each write now gets a later mtime.
- 027/1.2 `[ids] brackets` is in `src/config.ts` with the default false and the comment in `INIT_TEXT`. `src/adopt/plan.ts` reads an existing ID in both forms and writes new IDs in the configured form. A RENAMED FROM line takes the form of the main header. `src/check/check.ts` reads a bracketed TO line. The hint in `src/check/hints.ts` says to write each ID as its header writes it. `tests/adopt/brackets.test.ts` covers SCN-ADOPT-010-1 to SCN-ADOPT-010-4. The key count in `tests/config.test.ts` went from 16 to 17. The hint assertion of SCN-CHK-001-7 in `tests/check/base.test.ts` follows the new hint text.
- 027/1.3 `newIds` in `src/ids/ids.ts` returns the bracketed form for REQ and SCN when the key is true. `--for` accepts both forms. `tests/ids/new.test.ts` covers SCN-IDS-004-1 to SCN-IDS-004-4.
- 027/2.1 ADR-002 has the new line under Consequences. The README config block names the key. `CHANGELOG.md` has the items. `bun run ci:local` passed.

## By hand

- A copy of `tests/fixtures/no-id-repo` with `brackets = true` got 20 bracketed headers from `adopt`. `check` then printed only the six legacy task findings of the fixture, the same as after a bare `adopt`. One line: `openspec/changes/add-mfa/tasks.md:5  task-without-req  add-mfa/1.1`.
- Upstream OpenSpec 1.15.0 ran `validate --all --strict --no-interactive` on that copy. Three items passed. The released upstream reads the brackets as header text, so the bracketed form is safe before #1979 merges.
