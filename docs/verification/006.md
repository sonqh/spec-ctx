## Port

- Python `\w`, `\b`, `\s`, and `\d` are Unicode aware. The port uses `\p{L}`, `\p{N}`, `\p{Nd}`, and the exact `str.isspace()` set in their place.
- Columns and the 80 character cut count code points, as Python `len()` does. Masks of code spans keep the code point count.
- `round()` of the rate is half to even on the exact binary value. `--json` prints it as a Python float, for example `25.0`.
- `ste --json` escapes non ASCII text, as `ensure_ascii=True` does. `tells --json` does not.
- The `tells` flags keep the argparse rules: option prefixes such as `--base`, and one run of files only.
- A one time differential run outside the repository compared both implementations on 300 random texts and 25 flag sets. Every pair was identical.
